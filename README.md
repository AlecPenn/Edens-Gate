# Eden's Gate

A free music library from Alec Penn Radio: browse, listen, download. Everything is CC0.

- The songs live on the Internet Archive (`archive.org/details/alecpennradio-*`).
- `public/library.json` lists them (same format as the radio's `station.json`); `public/covers` holds small cover images.
- Plain static site: `public/index.html`, `public/styles.css`, `public/app.js`. No build step.
